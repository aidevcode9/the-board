## Overview

Code generation interviews assess your ability to design, evaluate, and improve LLM-powered coding systems. Key topics include prompt engineering for code, context window management, evaluation of generated code, and the trade-offs between different generation strategies (single-shot, iterative refinement, multi-agent).

---

## Core Concepts

### Context Window Management
- **Definition:** Strategies for fitting relevant code, documentation, and instructions within a model's token limit.
- **Interview relevance:** Real-world code generation requires managing large codebases that exceed context windows.
- **Common misconception:** "Bigger context window = better code generation" — retrieval quality matters more than raw window size.

### Code Evaluation
- **Definition:** Systematic assessment of LLM-generated code for correctness, security, performance, and maintainability.
- **Interview relevance:** Knowing how to evaluate generated code is as important as knowing how to generate it.
- **Common misconception:** "If it passes tests, it's good code" — test coverage, edge cases, and security vulnerabilities require deeper analysis.
