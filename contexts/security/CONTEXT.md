## Overview

Security interviews for AI engineering roles cover both traditional application security (OWASP Top 10) and emerging LLM-specific threats (prompt injection, data poisoning, model extraction). ---

## Core Concepts

### Prompt Injection
- **Definition:** Adversarial input that causes an LLM to deviate from its intended behavior by overriding system instructions.
- **Interview relevance:** The #1 LLM-specific vulnerability; every AI engineer must understand attack vectors and mitigations.
- **Common misconception:** "Input validation alone prevents prompt injection" — defense requires layered approaches including output filtering, privilege separation, and monitoring.

### OWASP Top 10 for LLM Applications
- **Definition:** A standardized list of the most critical security risks in LLM-based applications.
- **Interview relevance:** Demonstrates awareness of the security landscape beyond just model performance.
- **Common misconception:** "Traditional web security doesn't apply to AI" — LLM apps still face XSS, SSRF, and injection attacks alongside LLM-specific threats.
